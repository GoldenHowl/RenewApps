# 🌱 RenewApps

**Reviving the past, one executable at a time.**

RenewApps is an open-source initiative focused on restoring and modernizing legacy software for outdated or unsupported systems — Windows XP, Windows 7, early Android versions, and lightweight Linux distributions. We aim to preserve old tools, eliminate bloat, and bring usability back to forgotten machines.

---

## 🧠 Why?

Because good software doesn’t stop being good just because time passes.

- Old laptops still boot.
- Ancient phones still connect.
- And sometimes, a 2MB `.exe` does more than a bloated 300MB “modern” app.

Whether you’re reviving a netbook from 2009, dual-booting XP for fun, or trying to keep tech alive in low-resource environments, **RenewApps** is here to help.
